# estamp デザイン仕様（Banto Works 共通ルール＋和暦入力）

状態：清書（2026-10-22 JST）。和暦の範囲・手入力の形式・書体・明治の扱いはちゃろさん確認済み。色と角丸の数値はデザイン部の確定案。

## 1. Banto Works 共通ルール

### アイコン
- 正方形キャンバス、外周12.5%を余白にし、図柄は中央75%に収める。
- 製品ごとに単純な図形1つで区別する（estamp＝丸印、PLCタグ・モニタ＝荷札など）。文字や色だけで区別しない。
- 32px以下は文字を省いた簡略版に差し替える。.ico には 256/48/32/16 を同梱する。

### 色
| 役割 | 値 | 使い方 |
|---|---|---|
| 主色（藍） | `#243B6B` | ヘッダ、主ボタン |
| 補助色（青） | `#2563EB` | リンク、フォーカス枠（2px） |
| 印影色（朱） | `#C74332` | estampの印影とアイコンだけに使う。エラーには使わない |
| 背景 | `#F7F6F2` | 画面の地 |
| 文字 | `#1F1F1F` | 本文 |
| 補助文字・境界線 | `#8A8F98` | 注記、1px境界線 |
| 正常 | `#18794E` | |
| 注意 | `#8A5700` | |
| 異常 | `#B42318` | |
状態色は必ず記号（○△×）か文言を併記し、色だけで伝えない。

### 書体（すべてOFL 1.1。著作権表示とライセンス全文を配布物に同梱）
- UI：BIZ UDPゴシック（本文14px以上、見出しは太字）
- 印影：Shippori Mincho B1（estampでは印影の文字とアイコンの文字だけに使い、画面の見出しやボタンはBIZ UDPゴシック）
- 数値・タグ名：等幅書体（JetBrains Monoなど）。PLCタグ・モニタなど工場向け製品用で、estampの画面では使わない

### 角丸・影・寸法
- 角丸：入力欄 4px、ボタン・カード 8px、ダイアログ 12px。
- 影は2段だけ：浮き `0 1px 3px rgba(0,0,0,.12)`、重ね `0 4px 12px rgba(0,0,0,.16)`。通常の面は1px境界線。
- 間隔は4px単位、基本の余白16px。押す場所の高さは32px以上、工場向け製品は44px以上（手袋での操作）。

## 2. estamp アイコン
- 採用候補：案A「朱色の丸印を2本線で3段に分けた形」。16pxでも円と2本線が残る。
- 印影の書体は Shippori Mincho B1、配布アイコンの文字はアウトライン化する。16px・32pxは実寸で確認してから確定する。

## 3. 和暦の入力仕様（確定）

### 対応範囲（両端の日を含む）
| 元号 | 略号 | 受付範囲（西暦） |
|---|---|---|
| 明治 | M | 1873/1/1〜1912/7/29 |
| 大正 | T | 1912/7/30〜1926/12/24 |
| 昭和 | S | 1926/12/25〜1989/1/7 |
| 平成 | H | 1989/1/8〜2019/4/30 |
| 令和 | R | 2019/5/1〜 |
- 明治5年以前、および西暦で1873年より前の日付は「旧暦は未対応」としてはじく。

### 入力
- 元号のプルダウン＋年・月・日。年は元号ごとの上限で絞り、1年は「元年」と表示する。
- 手入力欄で受け付ける形式：`R7.10.22`、`令和7年10月22日`、`2025/10/22`、`2025-10-22`。
- `R元.5.1` のような「元」は1年として扱う。月・日は1桁でも受け付ける。
- 略号 M/T/S/H/R は大文字小文字を区別しない。全角数字は半角にする。元号なしの年は西暦4桁だけ。
- 内部では時刻を持たない年月日で保持し、プルダウンと手入力で同じ検証を使う。

### 表示
- 確定後に `令和7年10月22日（2025/10/22）` のように和暦と西暦を並べて表示し、印影のプレビューを更新する。

### 検証とエラー
- 検証の前に正規化する（全角数字と全角記号を半角に、略号を大文字に、「元」を1に）。
- 検証の順番：形式、実在する日か（閏年を含む）、元号の期間内か。
- 範囲外の組み合わせは自動で直さずエラーにし、正しい書き方を添える。
  - 例：「平成31年5月1日は平成の期間外です。正しい表記は令和元年5月1日です。」
  - 令和0年のような存在しない年もエラーにする。
- エラーは入力欄の直下に記号付きで1行表示し、読み上げにも通知する。入力値は消さない。直るまで印影の出力を止める。
