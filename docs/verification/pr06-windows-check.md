## 1. 準備・ビルド

検証専用のWindows 11 x64通常ユーザーと、依存導入済みのリポジトリを使う。既存の `%APPDATA%\jp.tyaro.estamp` がある場合は勝手に移動・上書きせず、別の検証ユーザーを用意する。既存アプリ・Office文書を終了しない。設定を書き込む試験はこの専用ユーザーだけで行う。

対象コミット／差分、OSビルド、画面解像度、表示倍率、WebView2、Node/Yarn/Rust、Officeの版、EXEのSHA-256を記録。lockを変更せず、ビルド・テストは必ず直列、Cargoは並列2。計測用の2変数を外し、通常releaseを作る。

```powershell
$env:COREPACK_ENABLE_NETWORK='0'
Remove-Item Env:VITE_PR05_MEASURE -ErrorAction SilentlyContinue
Remove-Item Env:ESTAMP_PR05_MEASURE -ErrorAction SilentlyContinue
corepack yarn run check
# 各行の $LASTEXITCODE が0であることを確認してから次へ進む
cargo check -j 2 --locked --offline --manifest-path src-tauri/Cargo.toml
cargo test -j 2 --locked --offline --manifest-path src-tauri/Cargo.toml
corepack yarn build
node node_modules/@tauri-apps/cli/tauri.js build --no-bundle -- --locked --offline -j 2
git diff --exit-code -- yarn.lock src-tauri/Cargo.lock
Get-FileHash src-tauri/target/release/estamp.exe -Algorithm SHA256
```

証跡はリポジトリ内の `outputs/pr06-windows/` へ保存し、コマンド出力の拡張子は `.txt` を使う。outputsは追跡しない。共有PCのネットワーク設定・キャッシュ・ツールチェーンを変更しない。表示倍率の変更も他の利用者と調整した検証環境で行う。回線遮断できない場合は「未実施」とし、接続中の確認で代替合格にしない。

## 2. DPI・最小サイズ・IME・長文エラー

**100／150／200%それぞれ**で通常releaseを起動し、次を実施する。OSの倍率を変えたら再起動してから試す。CSSの100px印影は100／150／200物理pxに相当する。画像出力の指定pxとは分けて記録する。

1. 初期250×120、最大250×310、可変サイズを維持していること。保存済みなら印影と右上の設定ボタンで起動すること。未保存なら§6の初回案内を確認すること。トレイは追加しない。
2. 設定ボタンで設定を開き、ウィンドウを最大の高さへ伸ばす。縦スクロールで「印影の設定」、全入力、保存、再読込、About／ライセンスへ届くこと。縮めても250×120より小さくならず、Tabで下の部品へ移るとその部品が見えること。設定や長い案内に横スクロール・重なり・欠けがないこと。
3. IMEで上段「国際事業推進部」、下段「髙橋渡邊」を入力。変換中のEnterが保存・コピーを発火しないこと。変換候補と確定文字の位置、各入力と保存の到達性を確認。日付も「令和7年10月22日」を変換し、変換確定後に和暦と西暦が併記されること。確定後の入力・保存・再起動復元を確認する。
4. 日付に `H31.5.1` を入力。入力直下で **「× 平成31年5月1日は平成の期間外です。正しい表記は令和元年5月1日です。」** が複数行に折り返され、末尾まで読めること。次に `1872-01-01` で **「× 旧暦は未対応です（1873年1月1日以降を入力してください）。」** を確認。入力値と最後の正常な印影は保持され、保存・コピーは無効になること。
5. 実際の250pxウィンドウ（スクロールバー分を差し引いた内幅）、初期高さ／最大高さの両方でエラーの末尾まで縦スクロールで読めること。横スクロール・省略記号・1行固定で逃げないこと。入力欄自体の編集カーソルによる横移動と、エラー本文の横スクロールは区別する。
6. `R元.5.1` へ訂正し、エラー消去・保存／コピー再有効化を確認。「今日に戻す」、西暦／和暦、文字サイズ1〜400・出力1〜4096の整数検証も確認する。

各倍率で起動、設定入力、2種類の長文エラー、保存ボタンへのフォーカス、Aboutを撮影する。高さ制限があるため全設定が同時に見えることは要件にせず、スクロールとフォーカスによって到達できることを判定する。

### 250×120での通知（レビュー修正）

- 各倍率の通常releaseで、縦スクロールを先頭に戻した250×120のまま印影をクリックする。印影枠の下端に14pxの「○ コピー成功」がスクロールなしで全文表示され、約1.8秒後に消えること。表示中の再クリックとEnter／Spaceもコピーでき、再成功から約1.8秒に表示時間が更新されること。詳細の既存メッセージは下方に残ること。
- 専用の検証環境でclipboard書込みを失敗させる（例：検証用ヘルパーでOpenClipboardを保持）。「× コピー失敗」が枠内に表示され、10秒以上待っても消えないこと。以前のclipboard画像が残っていても今回の成功と誤認しないこと。解放後、通知の上をクリック／キーボードで再試行でき、次の結果に置き換わること。失敗再現条件と実施有無を記録し、単体テストだけで実機合格にしない。
- コピー生成中に印影を変更できる検証条件では「△ コピー中止」を確認。成功・中止はNarratorでpolite、失敗はalert／assertiveで通知され、色だけに依存しないこと。
- 専用ユーザーで設定読込／保存の失敗を再現し、小窓の印影枠上端に「× 設定エラー」が残ること。保存失敗後にコピーが成功してもこの表示が消えず、再読込／保存の復旧で消えること。読込警告は「△ 設定に注意」、書体失敗は「× 書体エラー」で分かり、下方の詳細本文へ到達できること。設定の原本や他ユーザーの権限を変更しない。
- 成功・失敗・設定エラーとの同時表示を撮影し、枠外へのはみ出し、通知同士の重なり、クリック／フォーカス妨害、本番CSP違反がないことを確認する。

## 3. キーボード・読み上げ

- マウスなしでTab／Shift+Tabを使い、設定ボタンと印影へ届くこと。設定を開いた後は「閉じる」→上段→日付→下段→出力サイズ→保存→再読込→ライセンスへ移動する。各サイズ・日付形式・今日に戻すにも到達でき、フォーカスが2pxの青枠で見え、画面外へ隠れないこと。
- 印影にフォーカスし、EnterとSpaceをそれぞれ押して1回ずつ画像がコピーされること。Spaceでページが動いたり二重コピーにならないこと。無効時・変換中は出力しないこと。
- selectの矢印操作、ライセンスのEnter／Spaceによる展開、旧設定がある場合の取込確認とキャンセルを確認。PR-02の専用の旧設定コピーだけをEXE隣へ置き、既存ファイルがあれば上書きしない。
- Narratorで入力ラベル、印影の「印影をコピー」、日付の不正状態とエラー／確認文が読まれること。`date-input` の `aria-describedby` が `date-help date-error date-confirmation` に関連付くこと。通知は「○△×＋文言」で伝わり、色だけに依存しないこと。

## 4. 本番CSP・権限・書体・画像

開発サーバーを止め、通常releaseで行う。devのCSPはHMR用のローカルHTTP/WSとスタイル注入を許可するため、本番判定に使わない。

- 同梱のBIZ UDPゴシック400/700としっぽり明朝B1 400/700が読み込め、欠字や代替書体にならないこと。[PR-05手順 §2](pr05-windows-check.md#2-os書体に依存しない字形) の原本ハッシュ・別名・プレビューと画像の比較を再実施する。
- 上段・下段・和暦を編集し、50／100／200pxの透過画像をコピー。`scripts/verify/Get-Pr05Clipboard.ps1` を `pwsh -NoProfile -STA -File` で実行し、PNG実寸・四隅alpha・形式を保存。Paint、導入済みならWord／Excelへ貼り、空画像・欠け・字形差がないことを確認する。長い名前の100px表示は§6で確認する。
- 保存／再読込／旧設定の存在確認と確認付き取込がmainで権限エラーなく動くこと。ソース・生成された `src-tauri/gen/schemas/acl-manifests.json`／`capabilities.json`（生成名は実ファイルを確認）を照合し、main・localのみ、設定4コマンドと画像作成／書込み／解放の7権限で、remote・clipboard読取り・window作成権限がないことを記録する。
- `cargo test` のmainラベル拒否／ローカルorigin限定／IPC保存引数のテストと、JSのcapability／command整合テストが合格すること。別ウィンドウからの実IPC拒否は本PRで試験窓を追加していないため、必要なら検証専用ビルドで別途行い、実施有無を明記する。ソース検査を実IPC試験の合格とは呼ばない。
- 本番CSPは `tauri.conf.json` の文字列を証跡へ転記。実際の資源に対するCSP違反がないか、利用可能ならWebView2の診断を確認する。開発ビルドの結果やビルド成功だけで本番CSP互換を合格にしない。
- Aboutのバージョンがpackage／Tauri／Cargoの版と一致し、本体MIT・両OFL・第三者一覧・旧テーマMIT全文がオフラインで読めること。UIに外部リンク・外部ページ表示がないこと。
- 通常releaseで計測表示・計測ファイルが出ないこと。必要ならこの試験用に `ESTAMP_PR05_METRICS` をoutputs内の未存在CSVへ指定して起動し、ファイルが作成されないことを確認して変数を外す。計測コマンドと追加権限は `ESTAMP_PR05_MEASURE=1` のビルドだけで有効。
- 利用を許可されたオフライン検証環境で起動・編集・保存・コピー・ライセンスを確認する。WebView2基盤の通信とアプリ資源要求を区別する。

## 6. PR-06b：設定の入口と長い氏名

専用ユーザーで、100／150／200%それぞれ確認する。既存ユーザーの設定を削除しない。起動時250×120・上限250×310と縦スクロールを維持し、設定操作でウィンドウ自体の高さは変更しない。

1. **初回**: 保存先の `Setting.json` が無い状態で起動する。「印影の設定」が自動で開き、見出しへフォーカスし、「はじめに氏名などを入力し保存してください」が読めること。スクロールで入力・保存・再読込・Aboutへ届くこと。
2. **保存せず閉じて再起動**: 「閉じる」で設定が隠れ、先頭へ戻り、設定ボタンにフォーカスが戻ること。100px印影の直下に「△ 設定が未保存です（Ctrl+,）」が250×120で全文見えること。保存ファイルは作成されず、アプリを終了して再起動すると再び自動で開くこと。
3. **保存後**: 氏名などを入力して保存し、初回案内が消えること。閉じて再起動すると設定は自動では開かず、右上の歯車と印影が表示されること。保存した値がプレビューと設定欄へ復元されること。保存失敗の場合は初回扱いが継続すること。
4. **入口・キー・フォーカス**: 設定ボタンは右8px・上8px、押下領域32×32px、歯車16px、色 `#5F6470`。スクロール中も常時表示されること。ホバーで「設定（Ctrl+,）」、Narratorで「設定」を確認。Tabのフォーカスリングは2px `#2563EB`。クリック・Enter／Space・`Ctrl+,`で設定を開き、見出しへ移動すること。`Esc`または「閉じる」で設定ボタンへ戻ること。開閉を複数回繰り返し、隠れた入力へTab移動しないこと。IME変換中のキーが開閉や保存・コピーを起こさないこと。トレイは作らない。
5. **旧設定・破損**: 保存先に有効な旧形式の設定がある場合は自動で開かない。EXE隣に旧設定があるだけなら初回扱いを維持し、既存の確認付き取込が利用できること。取込成功で初回案内が消え、再起動後も閉じた状態になること。破損ファイルを退避できた場合は警告を保持して初回扱いとなり、未保存で再起動すれば再び案内すること。権限エラー・未対応schemaなどloadが失敗した場合は「設定なし」と断定せず、設定を開いてエラーと再読込を提示し、保存を止めること。
6. **長い氏名の100px表示**: 上段に `国際事業推進部 髙橋渡邊`、次に下段にも同じ値を入力する。半角空白・全角空白それぞれで「国際事業推進部」「髙橋渡邊」の2行となり、日付は1行のままであること。出力100pxでコピーし、プレビューと貼付画像の字形・行数・欠けを比較する。同梱Boldの字形寸法を読むNodeテストの基準は、各段2行、文字高約9.490／9.500px、横圧縮約78.158%。WebView2の描画で9px以上・75%以上を保ち、2行の間や罫線との重なりがないことを確認・撮影する。CSS100pxと物理pxを区別し、拡大画像だけで可読性の合格にしない。
7. **8文字の注意**: 各入力を8文字・9文字にし、9文字ではその入力直下に `#8A5700` で「△ 8文字を超えるため縮小します。空白で2行に分けられます」が出ること。警告があっても保存・コピーが可能なこと。指定例は空白で7文字＋4文字になるため警告が出ないこと。空白で分けた各行を基準に判定し、訂正後に消えること。
8. **本番CSP**: 通常releaseで歯車・同梱書体・プレビュー・コピーが表示／動作すること。外部依存・インラインstyle・画像URLの追加はなく、`img-src 'self'`／`style-src 'self'` のまま動作することを確認する。

各項目の倍率・合否・再現入力・EXEハッシュ・スクリーンショット・Narrator結果を記録する。Nodeの構造／寸法テストやViteビルドをWindows実機確認の代替にはしない。

縮小の限界: 自動縮小は100pxプレビューで文字高9px・横圧縮75%で止める。空白のない極端な長文は、その下限では枠幅に収まらず、SVG領域を超える部分が欠ける場合がある。省略・無条件の折返し・保存やコピーの禁止は追加しない。空白で2行に分ける運用と、限界時の見せ方の今後の判断が必要。利用者が明示的に指定した小さい文字サイズ（従来どおり1〜400）は拡大しないため、自動縮小の9px下限とは区別する。
